# Contributing

Issues are welcome: bug reports, questions and feature requests all help.

This repository is a read-only mirror of the released files and does not accept outside pull requests.
Open an issue instead; the description of the problem is what matters most. Include the
`plurai-extract` version, the Python version, the source type, and a minimal reproduction where
you can.

To report a security problem, follow [SECURITY.md](SECURITY.md) and do not open a public issue.
